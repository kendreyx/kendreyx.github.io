# 使用 Sveltia CMS 管理博客

管理入口：<https://blog.kendrey.top/admin/>，也可点击博客页脚的“文章管理”。电脑、手机使用相同入口。

## 首次登录

1. 使用拥有本博客仓库写入权限的 GitHub 账号打开[创建访问令牌页面](https://github.com/settings/personal-access-tokens/new?name=Kendrey+Blog+CMS&contents=write)。
2. 在 **Repository access** 选择 **Only select repositories**，仅选中 `kendreyx.github.io`；在仓库权限中确认 **Contents: Read and write**。无需授予 Actions、Workflows 或账户管理权限。
3. 设置有效期并创建令牌，然后在后台选择“使用个人访问令牌登录”，将令牌填入登录框。令牌仅用于自己的浏览器，不放进文章、配置文件或聊天。

后台会在当前浏览器记住登录。若令牌到期，重新创建后登录即可；公共设备使用后请退出。电脑登录后，也可在账号菜单使用“手机扫码登录”，将自己的登录同步到手机。该二维码包含认证信息，仅供自己扫码。

后台语言跟随浏览器语言，可在后台设置中切换。本文所述后台使用个人令牌登录；未来如需“一键 GitHub 登录”，可额外部署官方 OAuth 认证服务。

## 新建、查找、编辑和删除文章

- 打开“文章”，搜索标题或正文，或按日期排序。
- 新建文章后填写标题、日期、标签和正文。文件名会自动生成，中文标题也可直接使用。
- 新文章的“已发布”默认关闭，保存后仍是草稿。确认完成后打开“已发布”并保存，现有 GitHub Actions 将自动构建上线。
- 发布时可在“展示位置”选择“首页和归档”或“仅归档”。后者不出现在首页，但仍保留归档、搜索、RSS 和文章链接。
- 修改现有文章后保存即可更新；删除使用文章菜单中的删除操作。
- 正文编辑器支持排版和 Markdown；可从媒体库选择图片或上传。上传图片保存在 `img/posts/`。
- 页头默认使用文字样式；选择“图片页头”后，可设置页头图片。

保存和删除会生成 Git 提交，网站更新需要等待 Actions 构建完成。误删或误改可通过 GitHub 提交历史恢复。

## 草稿规则

后台统一管理 `_posts/`，使用文章的 `published: false` 保存草稿，`published: true` 公开发布。草稿不会进入公开首页、搜索或 RSS，即使文章日期在未来。

“已发布”与“展示位置”分别控制公开状态和首页展示：

| 已发布 | 展示位置 | 结果 |
| --- | --- | --- |
| 关闭 | 任意 | 草稿，不出现在博客前台 |
| 打开 | 首页和归档 | 出现在首页、归档、搜索和 RSS |
| 打开 | 仅归档 | 首页不展示，归档、搜索、RSS 和文章链接正常保留 |

现有文章没有 `hidden` 字段时默认仍在首页；后台选择“仅归档”后保存为 `hidden: true`。首页按可展示文章分页，不会因为隐藏文章留下空页。

本仓库公开，因此草稿的源文件仍可在 GitHub 仓库查看。

仓库原来的 `_drafts/post-template.md` 是手工写作模板，不出现在后台文章列表。`_posts/README.md` 也会被过滤。

## 维护

- 后台入口与字段配置分别为 `admin/index.html`、`admin/config.yml`；两者都是静态文件，不添加 Jekyll Front Matter。
- 当前固定 Sveltia CMS `0.250.0`，脚本通过 SHA-384 完整性校验加载。升级时同步更新版本和完整性校验值，并验证手机编辑及草稿发布流程。
- 站点访客的中英文切换与后台“文章语言”分别控制界面和文章标记，正文按作者填写的语言保存。
- 图床、公开附件、私密文件与限时分享的后续设计见[存储服务规划](Media-storage-plan.zh-CN.md)。当前上传仍保存到博客仓库，存储服务按规划另行开通。
